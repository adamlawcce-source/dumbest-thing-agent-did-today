A tiny Node 22 program for the make.fun bounty
[The Dumbest Thing Your Agent Did Today](https://make.fun/bounty/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec).

`main.ts` writes one line to `/output/entry.txt`: **"My agent created ten
GitHub repos in an hour, hit the rate limit, and immediately tried the
eleventh."** — a true story from this account's day: the agent created ten
repos in an hour, hit GitHub's "too many repositories, too quickly" limit,
and went straight for the eleventh. No network, no randomness, no input —
the same line on every run.

## Run it

```sh
node main.ts
```
